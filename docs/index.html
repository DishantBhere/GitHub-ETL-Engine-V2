01 / Why it exists

GitHub is full of signals.

Finding useful ones by hand means repeatedly searching, sorting, comparing and recording. This project turns that repeated work into one repeatable daily run.

01 / DISCOVER

Find fresh repos.

GitHub Search API pulls repositories created within the configured window, ordered by stars.

02 / UNDERSTAND

Measure momentum.

Raw fields become velocity, age, fork ratio and viral tiers so popularity has context.

03 / DELIVER

Make it readable.

One load becomes analysis tables, an Excel dashboard and a daily report people can consume.

03 / Transformation

Popularity gets context.

Stars alone can reward older repositories. The engine adds age and velocity, letting fast-moving projects surface beside established ones.

Signal =
stars ÷ age

stars_per_hour = stars / age_hoursAge is calculated from repository creation time. Values are rounded before storage. Lower age + strong stars → stronger momentum signal.

Then it ranks the signal.

Every repository receives a viral_level based on star thresholds, from Normal through Trending, Rising Star, Viral, Super Viral, Iconic, Legendary and Hall of Fame.
